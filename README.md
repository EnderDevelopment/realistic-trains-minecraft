# RealisticTrains

RealisticTrains is a Minecraft mod that adds 3D trains and rails to the game. This mod is designed to enhance the gameplay experience by providing a more realistic and immersive train transportation system. It includes custom train entities and rail blocks that can be used to create intricate train networks.

## Install

1. Download the mod file from the GitHub repository.
2. Place the downloaded file into the `mods` folder of your Minecraft instance.
3. Launch Minecraft with the Fabric mod loader installed.

## Use

1. Craft or obtain the rail blocks using the in-game crafting system.
2. Place the rail blocks to create tracks for the trains.
3. Craft or obtain the train entity.
4. Place the train entity on the rail tracks.
5. Ride the train by right-clicking on it.
